Pre-curriculum — Project Setup 2026-07-26

Covered: Full 40-session Python Fundamentals curriculum designed, mirroring the structure of the source React course. Repository structure created. All documentation infrastructure generated. No code written yet.

Decisions made: pip, minimal CSS dark theme (reused from the source course), plain Python (no external framework), static HTML docs, mock data before real APIs, a single running project — the Country Explorer — built incrementally across the 44-session core curriculum (plus 3 optional bonus sessions).

Next: Session 01 — Hello, World & Variables.

Layer 0 — Python Basics (Sessions 01–04)

Covered: A true starting point for anyone new to programming: running code, naming values, branching, and repeating. Every later session assumes these are second nature.

Gate session: Session 04 — Loops.

Layer 1 — Python Foundations (Sessions 05–11)

Covered: Before we build anything, we must be fluent in the core data structures and control flow that every later session relies on: dictionaries, lists, functions, and error handling.

Gate session: Session 11 — Errors and Exceptions.

Layer 2 — Object-Oriented Basics (Sessions 12–19)

Covered: We start modelling real things as classes. Every concept here maps to something in Layer 1 — a class is just a structured way of grouping the dictionaries and functions you already know.

Gate session: Session 19 — Object Identity and Equality.

Layer 3 — State & Interactivity (Sessions 20–26)

Covered: State is data that changes over time. We learn to track it safely on objects, take input from a user, and compute values instead of duplicating them.

Gate session: Session 26 — Computed Properties.

Layer 4 — Mock Data (Sessions 27–30)

Covered: Real teams build against fake data before a real data source exists. We design data contracts and a data-access layer independent of where the data actually comes from.

Gate session: Session 30 — Designing Data Contracts.

Layer 5 — Testing (Sessions 31–35)

Covered: Testing is introduced gradually alongside the code it tests, using pytest. We test behavior — what a function or class does — not implementation details.

Gate session: Session 35 — Testing the Data Layer with Mocks.

Layer 6 — Architecture (Sessions 36–40)

Covered: With the foundations in place, we learn to structure a Python project for long-term maintainability: package layout, reusable modules, and recognizing tight coupling.

Gate session: Session 40 — Architecture Review.

Layer 7 — Real World (Sessions 41–44)

Covered: Only now do we touch the filesystem and a real network API. By this point we have the vocabulary to understand exactly what changed and why it matters.

Gate session: Session 44 — Capstone Review.

Layer 8 — Beyond the Fundamentals (Sessions 45–47)

Covered: Optional, bonus sessions beyond the core curriculum: decorators, generators and context managers, and packaging/virtual environments — closing the remaining gaps to a genuinely intermediate level.

Gate session: Session 47 — Packaging & Virtual Environments.
