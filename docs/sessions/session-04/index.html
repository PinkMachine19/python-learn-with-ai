Loops

2. Pre-Coding Quiz

Answer these before reading the concept explanation or writing any code. It is fine to get these wrong — that is the point. You need 4/5 to proceed to the lab.

Question 1 of 5

Given countries = ["Kenya", "Ghana", "Peru"] and for country in countries:\n print(country), what prints?

A for ... in loop runs its body once for every item in the list, binding country to each value in turn. Since the body is print(country), each name prints on its own line.
Question 2 of 5

What does range(5) produce when looped over?

range(5) produces 5 numbers starting at 0 and stopping BEFORE 5: 0, 1, 2, 3, 4. This "starts at 0, stops before the given number" behavior matches how list indexing works, which is why it is the default.
Question 3 of 5

What is the danger of writing while count < 10: without ever changing count inside the loop body?

A while loop keeps running as long as its condition is True. If nothing inside the loop body ever changes the value being checked, the condition never becomes False, and the loop never ends — you must update the checked value yourself, usually near the end of the loop body.
Question 4 of 5

Given a loop searching for the first country with population over 100 million, what does break do once it is found?

break exits the loop immediately and completely — useful once you have found what you were looking for and have no reason to keep checking the remaining items.
Question 5 of 5

Given for c in countries:\n if c["population"] < 1000000:\n continue\n print(c["name"]), what does continue do for a country with a small population?

continue skips only the remainder of the current iteration's body and moves the loop on to the next item — unlike break, the loop keeps going, it just skips printing for items matching the condition.

3. The Concept — Repeating Actions with for and while

The loop body runs once per item — country is rebound to a new value each time through.

for loops — repeating for every item in a collection

A for loop runs its body once per item in a list, binding a loop variable to each value in turn — no manual counting required.

countries = ["Kenya", "Ghana", "Peru"]

for country in countries:
    print(country)
# Kenya
# Ghana
# Peru

range() — repeating a specific number of times

When you want to repeat an action a fixed number of times (not tied to a list), range() generates the sequence of numbers to loop over.

for i in range(5):
    print(i)
# 0
# 1
# 2
# 3
# 4

# range(start, stop) — customise where it begins
for i in range(2, 5):
    print(i)  # 2, 3, 4

while loops — repeating until a condition changes

A while loop keeps running as long as its condition stays True. Unlike a for loop, nothing automatically ends it — you must change the checked value yourself inside the loop body, or it runs forever.

count = 0

while count < 5:
    print(count)
    count = count + 1   # without this line, the loop never ends!
# 0
# 1
# 2
# 3
# 4

break and continue

break exits a loop immediately and completely. continue skips only the rest of the current pass and moves on to the next item.

countries = [
    {"name": "Norway", "population": 5400000},
    {"name": "Kenya", "population": 54000000},
    {"name": "India", "population": 1428000000},
]

# break — stop as soon as we find what we need
for c in countries:
    if c["population"] > 100000000:
        print("Found one:", c["name"])
        break

# continue — skip small countries, but keep checking the rest
for c in countries:
    if c["population"] < 10000000:
        continue
    print(c["name"])

4. Lab

Lab objective: Iterate over a list with a for loop, repeat with range(), write a while loop, and use break and continue meaningfully.

What you will build

A file called loops.py.

Step-by-step instructions

1

Create the file and loop over a list of country names

# loops.py
countries = ["Kenya", "Ghana", "Peru", "Japan"]

for country in countries:
    print(country)
2

Use range() to print numbered positions

for i in range(len(countries)):
    print(i, countries[i])
3

Write a while loop that counts down from 5

Make sure the loop actually terminates.

count = 5
while count > 0:
    print(count)
    count = count - 1
print("Liftoff!")
4

Use break to stop as soon as a target is found

target = "Peru"
for country in countries:
    if country == target:
        print("Found", target)
        break
    print("Checked", country, "- not a match")
5

Use continue to skip items that do not match a condition

for country in countries:
    if len(country) < 5:
        continue
    print(country, "has 5 or more letters")

9. Reflection Questions

Think through these after the post-quiz. No right answer — they are for discussion.

  1. What would you observe on screen if you accidentally created an infinite while loop? How would you know something was wrong, and how would you stop it?
  2. Why does break stop the ENTIRE loop, while continue only skips the current pass? Can you think of a scenario where you would want one but not the other?
  3. Rewrite the range()-based numbered loop using enumerate(countries) instead (look up what it does). Which version is clearer to you right now?

10. What Breaks If This Knowledge Is Missing?

If a for loop does not feel completely automatic, everything ahead will be much harder than it needs to be.
